# 🏢 Apartment Price Prediction ML Service

Эндокринированный микросервис на базе машинного обучения для прогнозирования стоимости квартир. Проект реализует полный цикл разработки (Production-ready ML Pipeline): от загрузки сырых данных из СУБД до контейнеризации веб-сервиса.

## 🛠️ Стек технологий
* **Язык разработки:** Python 3.14
* **Работа с данными & ML:** Pandas, NumPy, Scikit-Learn, XGBoost
* **Базы данных:** PostgreSQL, SQLAlchemy, Psycopg3
* **Веб-сервис:** FastAPI, Uvicorn, Pydantic
* **Контейнеризация:** Docker

## 🚀 Как запустить проект

### Локальный запуск (Разработка)
1. Установите зависимости виртуального окружения:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите загрузку данных и обучение финальной модели:
   ```bash
   python src/training/train.py
   ```
3. Запустите веб-сервер API:
   ```bash
   uvicorn app.main:app --reload
   ```
4. Откройте интерактивную документацию Swagger UI: `http://127.0.0`

### Запуск через Docker (Production)
Сервис полностью контейнеризирован. Для сборки и запуска выполните:
```bash
docker build -t apartment-api:v1 .
docker run -d -p 8000:8000 --name apartment-service apartment-api:v1
```
